# PRD

## 背景

当前 `scripts` 的系统设置已基本切到 HTTP 后端，但 `决策中心`、`商品总表`、`商品比对` 仍深度依赖 Electron IPC，本地 Web 调试和后续多端接入都存在阻碍。

## 目标

1. 系统设置、决策中心、商品中心统一通过 `scripts-backend` 提供数据与计算能力。
2. 前端页面不再直接调用 `window.ipcRenderer.invoke(...)` 获取决策配置、商品总表和商品比对结果。
3. 商品总表支持后端导入、状态查询、筛选项查询、列表查询。
4. 商品比对支持后端运行，保留现有“UPC 精确匹配 + AI 模糊匹配 + 新品阈值判断”语义。

## 非目标

1. 本轮不处理活动中心、采购任务等其余业务模块。
2. 本轮不移除所有 Electron 能力，只收敛用户已点名的模块。
3. 本轮不做新的复杂运营规则重构。

## 成功标准

1. 系统设置四页继续可用，并保持走 HTTP 后端。
2. 决策中心配置页可以正常读取和保存阈值配置。
3. 商品总表页面可以查看状态、刷新索引、导入文件、查询列表。
4. 商品比对页面可以调用后端完成比对并展示结果。
